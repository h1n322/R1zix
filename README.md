# Rizix

**Комплексна платформа для аналізу фінансових ризиків, стрес-тестування та прогнозування на базі математичного моделювання та штучного інтелекту.**

## Про проєкт

**Rizix** — це сучасна фінансово-аналітична екосистема (Вебплатформа та кросплатформний мобільний застосунок), розроблена для кількісної оцінки ризиків інвестиційних портфелів. Платформа інтегрує класичні стохастичні математичні моделі (геометричний броунівський рух, модель Блека-Шоулза) з передовими технологіями машинного навчання (LSTM, GARCH) та генеративним штучним інтелектом (Gemini AI).

> *Проєкт розроблено в рамках науково-дослідницької роботи для Малої академії наук (МАН) України.*

## Основні функціональні модулі

| Модуль | Категорія | Опис |
| :--- | :--- | :--- |
| **Геометричний броунівський рух (GBM)** | *Math* | Базова стохастична модель (Монте-Карло) для генерації тисяч сценаріїв руху ціни активу за умови нормального розподілу дохідностей. |
| **Merton Jump-Diffusion** | *Math* | Розширена стохастична модель, яка додатково враховує раптові "стрибки" (jumps) ціни, що імітують непередбачувані новини чи кризи (Пуассонівський процес). |
| **Моделювання GARCH** | *Math* | Моделювання кластеризації волатильності. Дозволяє симулювати сценарії, де ринкові потрясіння минулого впливають на дисперсію майбутнього. |
| **Historical Bootstrapping** | *Math* | Історична симуляція, яка випадковим чином формує майбутні траєкторії на основі реальних минулих дохідностей, зберігаючи реальні ринкові "товсті хвости" (fat tails). |
| **Стрес-тестування** | *Math* | Симуляція найгірших макроекономічних сценаріїв (наприклад, "Криза 2008 року" або "Чорний лебідь") з примусовим застосуванням екстремальних шоків. |
| **Портфель Марковіца** | *Math* | Оптимізація мультиактивного портфеля. Знаходження "Ефективного рубежу" для максимізації очікуваної дохідності при заданому рівні ризику. |
| **AI-Аналітика (Gemini)** | *AI* | Автоматизована генерація аналітичних звітів щодо рівня ризику, аналіз фундаментальних новин компанії (Yahoo Finance) та надання персоналізованих рекомендацій. |
| **LSTM-нейромережа** | *AI* | Детерміноване прогнозування нелінійних патернів поведінки цінових рядів із застосуванням рекурентних нейромереж (Long Short-Term Memory). |
| **Кросплатформність** | *UI/UX* | Уніфікований доступ до інструментів через веб-інтерфейс (React) та мобільний застосунок (React Native / Expo). |

## Технічний стек

Архітектура проєкту побудована за мікросервісним принципом та оптимізована для хмарного розгортання (Cloud-native):

### 1. Frontend-клієнти (Веб та Мобільний застосунок)
* **React 18 + Vite:** Високопродуктивний SPA-додаток (розгорнуто на Vercel).
* **React Native (Expo):** Нативний мобільний застосунок для iOS та Android (`riskmate-mobile`).
* **Firebase Auth:** Захищена автентифікація користувачів (Google OAuth, Email/Password).

### 2. Math Engine (Обчислювальне ядро)
* **.NET 10 (C#) / ASP.NET Core:** Основний REST API для складних математичних розрахунків (розгорнуто на Render). Завдяки оптимізації багатопотоковості (Parallel Computing) забезпечує мілісекундну генерацію понад 10 000 траєкторій Монте-Карло.
* **Entity Framework Core + Neon PostgreSQL:** Хмарна реляційна база даних для персистенції історії симуляцій.
* **GitHub Actions:** Налаштований CI/CD конвеєр для безперервного тестування (xUnit) та інтеграції.

### 3. ML Service (Машинне навчання)
* **Python 3.12 + FastAPI:** Мікросервіс для ресурсомістких AI/ML задач (розгорнуто на Render).
* **TensorFlow / Keras:** Архітектура LSTM-моделей для аналізу часових рядів.
* **Arch / SciPy / NumPy:** Пакет для GARCH-моделювання та портфельної оптимізації Марковіца.
* **yfinance:** Інтеграція для швидкого завантаження актуальних ринкових даних та фінансових новин.
