# RISKMATE

**RiskMate** — це комплексний вебдодаток для прогнозування фінансових ризиків та аналізу інвестиційних портфелів. Проєкт об'єднує класичні мікроекономічні моделі з сучасними алгоритмами машинного навчання для оцінки волатильності активів (включаючи акції та криптовалюти).

Розроблено в рамках науково-дослід
ницької роботи для МАН України.

## Ключовий функціонал

*   **Симуляція Монте-Карло:** Генерація тисяч сценаріїв розвитку цін на основі геометричного броунівського руху (GBM).
*   **Оцінка ризиків (VaR та CVaR):** Розрахунок Value at Risk та Conditional Value at Risk для визначення максимальних та екстремальних втрат ("товсті хвости" розподілу).
*   **Інтеграція ШІ:** Використання LSTM-нейромереж (TensorFlow) для аналізу часових рядів.
*   **Модель Марковіца:** Оптимізація портфеля на основі історичної волатильності та кореляції активів.
*   **Інтерактивний Дашборд:** Візуалізація даних у реальному часі з підтримкою професійних графіків.
*   **Комерційна інфраструктура:** Авторизація через Firebase та система підписок через Stripe.

## Technical stack

**Бекенд (Мозок):**
*   Python 3.12
*   FastAPI (REST API)
*   Pandas, NumPy, SciPy (Математичне моделювання)
*   TensorFlow, Arch (Аналіз часових рядів та GARCH)
*   yfinance (Отримання ринкових даних)

**Фронтенд (Інтерфейс):**
*   React + Vite
*   Recharts / Lightweight Charts (Візуалізація даних)
*   Tailwind CSS (Стилізація)

**Інфраструктура:**
*   Firebase (Аутентифікація та база даних)
*   Stripe (Обробка платежів та вебхуки)


## ЛОКАЛЬНИЙ ЗАПУСК

### 1. Запуск Бекенду
\`\`\`bash
cd riskmate-back
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
\`\`\`

### 2. ЗАПУСК ФРОНТЕНДУ
```bash
cd riskmate-front
npm install
npm run dev
\`

### 3. ЗАПУСК Stripe Webhook
```bash
stripe listen --forward-to localhost:8000/api/webhook
\```
